# Derived — machine-extracted, regenerable 🤖

Everything in this folder is **auto-generated by the sync pipeline** from upstream sources
(Figma, repos, the live site). It is a faithful *mirror*, not the original.

## Rules

- **Do not hand-edit anything here.** The next sync overwrites it. To change a derived fact,
  fix the **upstream source** (see [CONTRIBUTING.md](../../CONTRIBUTING.md)).
- **Every file carries provenance frontmatter:**
  - `source` — where it came from (Figma file, repo, URL)
  - `last-synced` — when (your staleness check)
  - `generated-by` — which pipeline adapter produced it
- **Trust, but verify against the source** if a decision is high-stakes — especially if
  `last-synced` looks old.
- If a derived fact contradicts `canon/`, that's **drift** — surface it, don't silently pick
  one. Run `/drift`.

## What's here

Populated per the sources this brain registered (`../../sources.json`). Typical folders:

- `design-system/` — design tokens + component inventory (from Figma)
- `digital-experience/` — product page & user-flow map (from Figma)
- `products/skus/` — SKU & dieline reference (from Figma)
- `web/` — live-site page inventory (from the site)
- `repos/` — code repo summaries (from GitHub)

## Bootstrapping note (interim content)

Before a real sync is wired, a folder may be hand-populated so the repo isn't empty. Flag every
such file `interim: true` + `do-not-edit: true` (`_interim` in JSON) with a banner naming the
`/sync` that will replace it. Treat interim values as a best-effort snapshot — verify against
the upstream source until a real sync runs.
